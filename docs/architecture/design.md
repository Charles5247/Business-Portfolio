# Design System

## Colors (as specified by brand)
- `--color-primary-green: #9ECD59` — accents, success states, secondary CTAs
- `--color-primary-orange: #E87817` — primary CTA buttons, highlights, active nav
- `--color-charcoal: #222222` — body text, dark backgrounds
- `--color-white: #FFFFFF` — base background
- `--color-charcoal-soft: #4A4A4A` — secondary text
- `--color-surface-alt: #F6F7F4` — alternating section backgrounds (tinted off-white, not pure gray, to stay warm against the green/orange palette)

## Typography
- Headings: `"Barlow Condensed", "Oswald", sans-serif` — bold, condensed, industrial stencil-adjacent feel (confident, technical, not soft/startup)
- Body: `"Inter", "Segoe UI", sans-serif` — clean, highly readable at small sizes
- Scale: H1 44/56px, H2 32/40px, H3 22/28px, body 16/26px, small 14/20px

## Spacing
4px base scale: 4, 8, 12, 16, 24, 32, 48, 64, 96px

## Radius / Shadow
- Cards: 8px radius, subtle shadow `0 4px 20px rgba(34,34,34,0.08)`
- Buttons: 4px radius (sharper = more industrial than pill-shaped)

## Components
- Primary button: orange bg, white text, uppercase, letter-spacing 0.5px, hover darkens 8%
- Secondary button: transparent bg, white/charcoal border + text
- Service card: white bg, top icon in green circle badge, charcoal heading, gray body
- Trust bar: horizontal scroll/wrap of plain-text company names on charcoal strip
